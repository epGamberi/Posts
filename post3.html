O Padrão RGB: Transformando Cores em Números

Nesta semana, mergulhamos em um dos conceitos mais fundamentais da Computação Visual: o modelo de cores RGB. Foi o momento de deixar de lado a visão artística das imagens e começar a entender como o computador realmente as processa "por baixo dos panos".

Luz em vez de tinta

O RGB é um modelo de cor aditivo baseado em três canais de luz: Red (Vermelho), Green (Verde) e Blue (Azul). Diferente da mistura de tintas no papel (onde misturar todas as cores resulta em um tom escuro/preto), a tela do computador emite luz. Isso significa que, se você somar a intensidade máxima de vermelho, verde e azul, você obterá a cor branca.

A Imagem como uma Matriz Matemática

O maior "estalo" dessa aula foi entender a estrutura de dados de uma imagem. Para a máquina, uma fotografia não é um desenho; é uma gigantesca matriz bidimensional (uma grade de linhas e colunas) onde cada quadradinho é um pixel.

No padrão RGB padrão de 8 bits, cada pixel armazena a intensidade das três cores primárias com valores que vão de 0 a 255. Veja um exemplo prático de como o computador "lê" a cor de um único pixel vermelho puro:

Pixel = (255, 0, 0)
// 100% de luz vermelha, 0% verde, 0% azul
Pixel = (255, 255, 0)
// Misturando vermelho e verde temos Amarelo!

"Ao perceber que cada pixel é apenas um vetor numérico [R, G, B], fica fácil entender como a Visão Computacional funciona: alterar o brilho de uma foto ou aplicar um filtro não passa de realizar operações matemáticas de soma ou multiplicação em cima dessa matriz."

Por que isso importa?

Entender que as cores são números é a base para tudo o que faremos a seguir. Se quisermos que um algoritmo encontre uma "maçã vermelha" em uma foto, ele não vai procurar pelo conceito de maçã, mas sim buscar na matriz por clusters de pixels onde o canal R (Red) tem valores altíssimos enquanto G e B possuem valores baixos.
